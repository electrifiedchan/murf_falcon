# Day 8 – Advanced Analytics & Telemetry

Today involves building out proper telemetry and observing how our agent performs in real time.

For Day 8, your objective is to:

- **Step 1: Set up a Metrics Endpoint.** 
  - Added an API route to securely expose total, successful, and failed voice calls from local SQLite.
- **Step 2: Build a Custom Next.js Dashboard.** 
  - Designed the `Agent Telemetry Dashboard` located at `/dashboard`.
- **Step 3: Render Real-time Visualizations.**
  - Implemented Doughnut/Pie charts reflecting session outcomes in a modern UI.

### You've finished Day 8 if:

- Your Next.js Analytics dashboard correctly reads live backend AI interaction data from SQLite.
- The UI contains clear statistics on agent performance.
